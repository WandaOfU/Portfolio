Workflow Studio

A concept for agent-assisted pipeline building inside Cloud.ru's Evolution platform. Instead of assembling stages by hand on an empty canvas, you describe the engineering task in plain language and an agent proposes the steps — then hands you back an ordinary, editable workflow.

Entry point

An empty canvas is the worst first screen a builder can offer: it asks for the answer before the user has stated the problem. Replacing it with a prompt field inverts that. You describe the task, and the system does the decomposition.

The domain chips and template cards below exist for the other half of the audience. Someone who already knows the shape of their pipeline should not have to write a sentence to get to it, so the two entry modes sit on the same screen at the same level rather than behind a mode switch.

Agent canvas

While the agent works, the original request stays pinned in the left panel. That is a deliberate anchor: generated output is only judgeable against what was asked, and a user who has lost sight of their own prompt cannot tell a good result from a plausible one.

The YAML and Visual toggle sits in the same bar as zoom and fit. Treating the code view as a peer of the diagram, rather than an export buried in a menu, is what makes the result inspectable instead of opaque.

Generated workflow

The output is not a script but a graph of typed nodes, each carrying its service identity. That choice decides everything downstream: a graph can be rearranged, partially rerun and diffed, and a generated block of config cannot.

Dependency order is expressed spatially rather than stated. Networking resolves before the cluster, the cluster before the database, and the second example shows the agent is not limited to a chain: an API gateway fans out to three parallel services, so the proposal carries real topology.

Step catalog

The agent is one way in; the catalog is the other. Steps are grouped by domain — utilities, AI Factory, containers, applications, infrastructure, networking, disks, databases, data platform — and every group carries a plain-language line under it, because a name like AI Factory tells an engineer nothing about whether their model serving belongs there.

It opens as a drawer rather than a page, so the canvas stays visible behind it. Choosing a step is an act performed against a workflow you can still see, not a detour into a separate builder.

Saved scenarios

Once generated, a workflow becomes an ordinary listed object with author, updated and created columns. This is the quiet decision that keeps the feature from fragmenting the product: the agent is an entry point, not a parallel universe with its own storage and its own list.

Anything created by prompt lands in the same place as anything built by hand, and is managed with the same controls.
